1. 物理模型与运动方程

不考虑阻力。设水平方向上杆对车的力为 P P P，竖直方向删杆对车的力为 N N N。车受到水平方向上的外力 F F F。

对车（水平方向受力）

F−P=Mx¨ F - P = M\ddot{x} F−P=Mx¨

对杆（平动）

质心坐标（L=l/2L = l/2L=l/2 为转轴到质心距离）：

xc=x+Lsin⁡θ,yc=−Lcos⁡θ x_c = x + L\sin\theta, \qquad y_c = -L\cos\theta xc​=x+Lsinθ,yc​=−Lcosθ

质心加速度：

x¨c=x¨+Lcos⁡θ⋅θ¨−Lsin⁡θ⋅θ˙2 \ddot{x}_c = \ddot{x} + L\cos\theta\cdot\ddot{\theta} - L\sin\theta\cdot\dot{\theta}^2 x¨c​=x¨+Lcosθ⋅θ¨−Lsinθ⋅θ˙2 y¨c=Lsin⁡θ⋅θ¨+Lcos⁡θ⋅θ˙2 \ddot{y}_c = L\sin\theta\cdot\ddot{\theta} + L\cos\theta\cdot\dot{\theta}^2 y¨​c​=Lsinθ⋅θ¨+Lcosθ⋅θ˙2

杆的受力：

mx¨c=P（水平）,my¨c=N−mg（竖直） m\ddot{x}_c = P \quad \text{（水平）}, \qquad m\ddot{y}_c = N - mg \quad \text{（竖直）} mx¨c​=P（水平）,my¨​c​=N−mg（竖直）

转动

以质心为参考，惯性力矩为 0，转动惯量：

Jc=112ml2 J_c = \frac{1}{12}ml^2 Jc​=121​ml2

代入得运动方程组

{(M+m)x¨+l2m(θ¨cos⁡θ−θ˙2sin⁡θ)=FJcθ¨+l2mgsin⁡θ+l2mx¨cos⁡θ+l24mθ˙2sin⁡θ=0 \begin{cases} (M + m)\ddot{x} + \frac{l}{2}m\left(\ddot{\theta}\cos\theta - \dot{\theta}^2\sin\theta\right) = F \\[4pt] J_c\ddot{\theta} + \frac{l}{2}mg\sin\theta + \frac{l}{2}m\ddot{x}\cos\theta + \frac{l^2}{4}m\dot{\theta}^2\sin\theta = 0 \end{cases} ⎩⎨⎧​(M+m)x¨+2l​m(θ¨cosθ−θ˙2sinθ)=FJc​θ¨+2l​mgsinθ+2l​mx¨cosθ+4l2​mθ˙2sinθ=0​

令 L=l/2L = l/2L=l/2（连接处到质心位置），简化为：

{(M+m)x¨+mL θ¨cos⁡θ−mL θ˙2sin⁡θ=FJcθ¨+mgLsin⁡θ+mL x¨cos⁡θ+mL2θ˙2sin⁡θ=0 \begin{cases} (M + m)\ddot{x} + mL\,\ddot{\theta}\cos\theta - mL\,\dot{\theta}^2\sin\theta = F \\[4pt] J_c\ddot{\theta} + mgL\sin\theta + mL\,\ddot{x}\cos\theta + mL^2\dot{\theta}^2\sin\theta = 0 \end{cases} {(M+m)x¨+mLθ¨cosθ−mLθ˙2sinθ=FJc​θ¨+mgLsinθ+mLx¨cosθ+mL2θ˙2sinθ=0​

2. 线性化

可见上述方程组不是线性方程，需线性化。令

φ=π−θ \varphi = \pi - \theta φ=π−θ

表示杆偏离竖直向上的小角度。小角度近似（φ\varphiφ 很小时）：

sin⁡θ=sin⁡(π−φ)=sin⁡φ≈φ \sin\theta = \sin(\pi - \varphi) = \sin\varphi \approx \varphi sinθ=sin(π−φ)=sinφ≈φ cos⁡θ=cos⁡(π−φ)=−cos⁡φ≈−1 \cos\theta = \cos(\pi - \varphi) = -\cos\varphi \approx -1 cosθ=cos(π−φ)=−cosφ≈−1 θ=π−φ≈π⇒θ˙=−φ˙,θ¨=−φ¨ \theta = \pi - \varphi \approx \pi \Rightarrow \dot{\theta} = -\dot{\varphi}, \quad \ddot{\theta} = -\ddot{\varphi} θ=π−φ≈π⇒θ˙=−φ˙​,θ¨=−φ¨​

忽略二阶小量（如 θ˙2sin⁡θ\dot{\theta}^2\sin\thetaθ˙2sinθ 等），得到线性化方程组：

{(M+m)x¨+mL φ¨=FJcφ¨+mL x¨−mgL φ=0 \begin{cases} (M + m)\ddot{x} + mL\,\ddot{\varphi} = F \\[4pt] J_c\ddot{\varphi} + mL\,\ddot{x} - mgL\,\varphi = 0 \end{cases} {(M+m)x¨+mLφ¨​=FJc​φ¨​+mLx¨−mgLφ=0​
