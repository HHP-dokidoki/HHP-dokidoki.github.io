复数的幅角表示

动态系统建模与分析 · 学习笔记
2026年8月13日

1. 复数的几何表示

复数 zzz 在复平面上可表示为一点或一个向量：

  • 横轴为实轴（Re），纵轴为虚轴（Im）
  • 复数点坐标 (a,b)(a, b)(a,b)，即 z=a+bjz = a + bjz=a+bj（工程中虚数单位用 jjj 表示）
  • 从原点到该点的向量长度为模 ∣z∣|z|∣z∣，与实轴正方向的夹角为幅角 α\alphaα

2. 幅角表示（极坐标 / 指数形式）

由几何关系：

∣z∣=a2+b2,sin⁡α=Im⁡(z)∣z∣,cos⁡α=Re⁡(z)∣z∣ |z| = \sqrt{a^2 + b^2}, \qquad \sin\alpha = \frac{\operatorname{Im}(z)}{|z|}, \qquad \cos\alpha = \frac{\operatorname{Re}(z)}{|z|} ∣z∣=a2+b2​,sinα=∣z∣Im(z)​,cosα=∣z∣Re(z)​

于是：

z=∣z∣cos⁡α+∣z∣sin⁡α⋅j=∣z∣(cos⁡α+jsin⁡α)=∣z∣ ejα z = |z|\cos\alpha + |z|\sin\alpha \cdot j = |z|(\cos\alpha + j\sin\alpha) = |z|\,e^{j\alpha} z=∣z∣cosα+∣z∣sinα⋅j=∣z∣(cosα+jsinα)=∣z∣ejα

其中幅角 α=arctan⁡(Im⁡(z)Re⁡(z))\alpha = \arctan\left(\dfrac{\operatorname{Im}(z)}{\operatorname{Re}(z)}\right)α=arctan(Re(z)Im(z)​)。

3. 幅角表示下的运算性质

设 z1=∣z1∣ejα1z_1 = |z_1|e^{j\alpha_1}z1​=∣z1​∣ejα1​，z2=∣z2∣ejα2z_2 = |z_2|e^{j\alpha_2}z2​=∣z2​∣ejα2​，则：

  • 乘法：z1z2=∣z1∣∣z2∣ ej(α1+α2)z_1 z_2 = |z_1||z_2|\,e^{j(\alpha_1 + \alpha_2)}z1​z2​=∣z1​∣∣z2​∣ej(α1​+α2​)
  • 除法：z1z2=∣z1∣∣z2∣ ej(α1−α2)\dfrac{z_1}{z_2} = \dfrac{|z_1|}{|z_2|}\,e^{j(\alpha_1 - \alpha_2)}z2​z1​​=∣z2​∣∣z1​∣​ej(α1​−α2​)
  • 共轭：z=∣z∣ejαz = |z|e^{j\alpha}z=∣z∣ejα，zˉ=∣z∣e−jα\bar{z} = |z|e^{-j\alpha}zˉ=∣z∣e−jα

即：幅角表示下，复数乘法相当于模相乘、幅角相加；除法相当于模相除、幅角相减；共轭即幅角取反。
