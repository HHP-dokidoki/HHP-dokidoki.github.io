1. 冲激函数（狄拉克函数）

① 定义

δ(t)={∞,t=00,t≠0 \delta(t) = \begin{cases} \infty, & t = 0 \\ 0, & t \ne 0 \end{cases} δ(t)={∞,0,​t=0t=0​

且满足归一化条件（单位冲激函数）：

∫−∞+∞δ(t) dt=1 \int_{-\infty}^{+\infty} \delta(t)\,dt = 1 ∫−∞+∞​δ(t)dt=1

是一种广义函数。严格定义为与测试函数 φ(t)\varphi(t)φ(t) 的作用：

∫−∞+∞δ(t) φ(t) dt=φ(0) \int_{-\infty}^{+\infty} \delta(t)\,\varphi(t)\,dt = \varphi(0) ∫−∞+∞​δ(t)φ(t)dt=φ(0)

更一般地（平移）：

∫−∞+∞δ(t−t0) φ(t) dt=φ(t0) \int_{-\infty}^{+\infty} \delta(t - t_0)\,\varphi(t)\,dt = \varphi(t_0) ∫−∞+∞​δ(t−t0​)φ(t)dt=φ(t0​)
δ(t)\delta(t)δ(t) 的本质：一种**"采样算子"**——提取函数在冲激位置处的值。

② 性质

筛选性：

∫−∞+∞δ(t−t0) φ(t) dt=φ(t0),x(t) δ(t−t0)=x(t0) δ(t−t0) \int_{-\infty}^{+\infty} \delta(t - t_0)\,\varphi(t)\,dt = \varphi(t_0), \qquad x(t)\,\delta(t - t_0) = x(t_0)\,\delta(t - t_0) ∫−∞+∞​δ(t−t0​)φ(t)dt=φ(t0​),x(t)δ(t−t0​)=x(t0​)δ(t−t0​)

对称性：

δ(t)=δ(−t) \delta(t) = \delta(-t) δ(t)=δ(−t)

尺度变换：

δ(at)=1∣a∣δ(t),δ(at+b)=1∣a∣δ(t+ba) \delta(at) = \frac{1}{|a|}\delta(t), \qquad \delta(at + b) = \frac{1}{|a|}\delta\left(t + \frac{b}{a}\right) δ(at)=∣a∣1​δ(t),δ(at+b)=∣a∣1​δ(t+ab​)

卷积性质：

(φ∗δ)(t)=∫−∞+∞φ(τ) δ(t−τ) dτ=φ(t) (\varphi * \delta)(t) = \int_{-\infty}^{+\infty} \varphi(\tau)\,\delta(t - \tau)\,d\tau = \varphi(t) (φ∗δ)(t)=∫−∞+∞​φ(τ)δ(t−τ)dτ=φ(t) φ(t)∗δ(t−t0)=∫−∞+∞φ(τ) δ(t−t0−τ) dτ=φ(t−t0) \varphi(t) * \delta(t - t_0) = \int_{-\infty}^{+\infty} \varphi(\tau)\,\delta(t - t_0 - \tau)\,d\tau = \varphi(t - t_0) φ(t)∗δ(t−t0​)=∫−∞+∞​φ(τ)δ(t−t0​−τ)dτ=φ(t−t0​)

即：任意函数与冲激函数卷积 = 该函数本身；与 δ(t−t0)\delta(t - t_0)δ(t−t0​) 卷积 = 平移后的函数。

2. 与阶跃函数的关系

δ(t)=ddtu(t),u(t)=∫−∞tδ(ζ) dζ \delta(t) = \frac{d}{dt}u(t), \qquad u(t) = \int_{-\infty}^{t} \delta(\zeta)\,d\zeta δ(t)=dtd​u(t),u(t)=∫−∞t​δ(ζ)dζ

3. 冲激响应

定义：系统在单位冲激函数 δ(t)\delta(t)δ(t) 激励下产生的输出信号（系统须初始松弛）。

4. 利用冲激函数表示任意信号

① 筛选性质的直观理解

任意信号 x(t)x(t)x(t) 可看作一系列冲激函数的叠加：

x(t)=∫−∞+∞x(ζ) δ(t−ζ) dζ x(t) = \int_{-\infty}^{+\infty} x(\zeta)\,\delta(t - \zeta)\,d\zeta x(t)=∫−∞+∞​x(ζ)δ(t−ζ)dζ

推导思路：把 x(t)x(t)x(t) 按 Δt0\Delta t_0Δt0​ 分段，每段用一个面积为 x(kΔt0)Δt0x(k\Delta t_0)\Delta t_0x(kΔt0​)Δt0​ 的冲激近似：

x(t)=∑k=−∞+∞x(kΔt0) δ(t−kΔt0) Δt0 x(t) = \sum_{k=-\infty}^{+\infty} x(k\Delta t_0)\,\delta(t - k\Delta t_0)\,\Delta t_0 x(t)=k=−∞∑+∞​x(kΔt0​)δ(t−kΔt0​)Δt0​

当 Δt0→0\Delta t_0 \to 0Δt0​→0 时取极限即得积分形式。

② LTI 系统的三个性质

(1) 时不变性：输入 δ(t)→\delta(t) \toδ(t)→ 输出 h(t)h(t)h(t)；输入 δ(t−ζ)→\delta(t - \zeta) \toδ(t−ζ)→ 输出 h(t−ζ)h(t - \zeta)h(t−ζ)

(2) 齐次性：输入 δ(t)→\delta(t) \toδ(t)→ 输出 h(t)h(t)h(t)；输入 Aδ(t)→A\delta(t) \toAδ(t)→ 输出 Ah(t)Ah(t)Ah(t)

(3) 叠加性：输入 u1(t)→u_1(t) \tou1​(t)→ 输出 x1(t)x_1(t)x1​(t)；输入 u2(t)→u_2(t) \tou2​(t)→ 输出 x2(t)x_2(t)x2​(t)；输入 u1(t)+u2(t)→u_1(t) + u_2(t) \tou1​(t)+u2​(t)→ 输出 x1(t)+x2(t)x_1(t) + x_2(t)x1​(t)+x2​(t)

③ 核心推论：只需知道 h(t)h(t)h(t) 即可求任意输入下的输出

根据①②，信号可分解为冲激信号的叠加，而 LTI 系统对叠加的响应 = 响应的叠加。

输入分解：

x(t)=∫−∞+∞x(τ) δ(t−τ) dτ x(t) = \int_{-\infty}^{+\infty} x(\tau)\,\delta(t - \tau)\,d\tau x(t)=∫−∞+∞​x(τ)δ(t−τ)dτ

输出即为（卷积）：

∫−∞+∞x(τ) h(t−τ) dτ=x(t)∗h(t) \int_{-\infty}^{+\infty} x(\tau)\,h(t - \tau)\,d\tau = x(t) * h(t) ∫−∞+∞​x(τ)h(t−τ)dτ=x(t)∗h(t)

即系统输出 = 输入与冲激响应的卷积：

x(t)=∫−∞+∞u(τ) h(t−τ) dτ=u(t)∗h(t) x(t) = \int_{-\infty}^{+\infty} u(\tau)\,h(t - \tau)\,d\tau = u(t) * h(t) x(t)=∫−∞+∞​u(τ)h(t−τ)dτ=u(t)∗h(t)

5. 从另一角度看：冲激函数的拉氏变换

L{δ(t)}=∫−∞+∞δ(t)e−st dt=e0=1 \mathcal{L}\{\delta(t)\} = \int_{-\infty}^{+\infty} \delta(t) e^{-st}\,dt = e^0 = 1 L{δ(t)}=∫−∞+∞​δ(t)e−stdt=e0=1

对应拉氏变换域关系 X(s)=U(s)H(s)X(s) = U(s)H(s)X(s)=U(s)H(s)：

当输入为 δ(t)\delta(t)δ(t) 时，U(s)=L{δ(t)}=1U(s) = \mathcal{L}\{\delta(t)\} = 1U(s)=L{δ(t)}=1，故

X(s)=1⋅H(s)=H(s) X(s) = 1 \cdot H(s) = H(s) X(s)=1⋅H(s)=H(s)

故冲激响应就是传递函数：H(s)=L{h(t)}H(s) = \mathcal{L}\{h(t)\}H(s)=L{h(t)}，即传递函数是冲激响应的拉普拉斯变换。
