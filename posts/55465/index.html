从根轨迹到 PID 控制

动态系统建模与分析 · 学习笔记
2026年8月10日

引言

反馈系统的稳定性由其闭环极点唯一确定，即由特征方程的根决定。简单的判稳方法是计算特征方程的根，但对于高阶系统或系统参数变化的情况，计算将十分繁杂。

鉴于此，伊凡思（Evans） 提出了以图解特征方程根的方法，即根轨迹法。

一、闭环系统的传递函数与开环传递函数

闭环传递函数（R(s)R(s)R(s) 到 Y(s)Y(s)Y(s)）：

T(s)=Y(s)R(s)=K G1(s)1+K G1(s)H(s) T(s) = \frac{Y(s)}{R(s)} = \frac{K\,G_1(s)}{1 + K\,G_1(s)H(s)} T(s)=R(s)Y(s)​=1+KG1​(s)H(s)KG1​(s)​

开环传递函数即闭环系统在比较点处断开后，从 E(s)E(s)E(s) 到 B(s)B(s)B(s) 的传递关系：

L(s)=B(s)E(s)=K G1(s)H(s) L(s) = \frac{B(s)}{E(s)} = K\,G_1(s)H(s) L(s)=E(s)B(s)​=KG1​(s)H(s)

可以发现：

T(s)=K G1(s)1+L(s) T(s) = \frac{K\,G_1(s)}{1 + L(s)} T(s)=1+L(s)KG1​(s)​

通过 T(s)T(s)T(s) 可分析系统的响应特性与稳定性。而系统特征方程

1+L(s)=0 1 + L(s) = 0 1+L(s)=0

说明闭环极点即为 L(s)=−1L(s) = -1L(s)=−1 的根。那么可通过 L(s)L(s)L(s) 分析系统稳定性，后者显然更方便。

二、根轨迹

1. 何为根轨迹

特征方程：

1+L(s)=0⟺L(s)=−1⟺KG(s)H(s)=−1 1 + L(s) = 0 \quad \Longleftrightarrow \quad L(s) = -1 \quad \Longleftrightarrow \quad KG(s)H(s) = -1 1+L(s)=0⟺L(s)=−1⟺KG(s)H(s)=−1

根轨迹定义：特征方程中参数（比例增益 KKK）从 000 到 +∞+\infty+∞ 变化时，所有根 sss 在复平面上扫出的轨迹集合。

2. 幅值条件与相角条件

由 KG(s)H(s)=−1KG(s)H(s) = -1KG(s)H(s)=−1：

幅值条件：

∣K G(s)H(s)∣=1 |K\,G(s)H(s)| = 1 ∣KG(s)H(s)∣=1

相角条件：

∠G(s)H(s)=(2n+1)π,n=0,1,2,… \angle G(s)H(s) = (2n+1)\pi, \quad n = 0, 1, 2, \dots ∠G(s)H(s)=(2n+1)π,n=0,1,2,…

设 G(s)H(s)=(s−z1)(s−z2)⋯(s−zm)(s−p1)(s−p2)⋯(s−pn)G(s)H(s) = \dfrac{(s - z_1)(s - z_2)\cdots(s - z_m)}{(s - p_1)(s - p_2)\cdots(s - p_n)}G(s)H(s)=(s−p1​)(s−p2​)⋯(s−pn​)(s−z1​)(s−z2​)⋯(s−zm​)​，其中 θk\theta_kθk​ 为从零点 zkz_kzk​ 到点 sss 的向量夹角，φk\varphi_kφk​ 为从极点 pkp_kpk​ 到点 sss 的向量夹角，则相角条件可写为：

∑k=1mθk−∑k=1nφk=(2n+1)π \sum_{k=1}^{m}\theta_k - \sum_{k=1}^{n}\varphi_k = (2n+1)\pi k=1∑m​θk​−k=1∑n​φk​=(2n+1)π

判断一个点 sss 是否在根轨迹上，仅需检查其是否满足相角条件；若满足，可根据幅值条件求出对应的 KKK 值。

3. 手绘根轨迹的规则

设 L(s)=KG(s)H(s)=K⋅∏k=1m(s−zk)∏k=1n(s−pk)L(s) = KG(s)H(s) = K\cdot\dfrac{\prod_{k=1}^{m}(s - z_k)}{\prod_{k=1}^{n}(s - p_k)}L(s)=KG(s)H(s)=K⋅∏k=1n​(s−pk​)∏k=1m​(s−zk​)​，即 nnn 个极点、mmm 个零点。

1) 起点与终点：起点为开环极点，终点为开环零点。

由 1+L(s)=0⇒G(s)H(s)=−1K1 + L(s) = 0 \Rightarrow G(s)H(s) = -\frac{1}{K}1+L(s)=0⇒G(s)H(s)=−K1​：

  • K→0K \to 0K→0 时，轨迹起于极点
  • K→∞K \to \inftyK→∞ 时，轨迹终止于零点
  • 若 n>mn > mn>m：nnn 条轨迹起于极点，mmm 条终止于零点，剩余 n−mn - mn−m 条终止于无穷远处
  • 若 n<mn < mn<m：mmm 条起于零点，nnn 条终止于极点，剩余 m−nm - nm−n 条起于无穷远处

2) 分支与对称性：一定有 max⁡(n,m)\max(n, m)max(n,m) 条分支，且一定关于实轴对称（复数解一定共轭）。

3) 实轴上的根轨迹：实轴上零、极点将轴分段，若某段右侧的零、极点总数是奇数，则该段必为根轨迹的一部分（可用幅角条件证明）。

4) 渐近线：当极点数 nnn 大于零点数 mmm 时，n−mn - mn−m 条轨迹沿与实轴夹角 φk\varphi_kφk​、交于 σa\sigma_aσa​ 的渐近线趋于无穷：

φk=(2k+1)πn−m,σa=∑Pi−∑Zjn−m \varphi_k = \frac{(2k+1)\pi}{n - m}, \qquad \sigma_a = \frac{\sum P_i - \sum Z_j}{n - m} φk​=n−m(2k+1)π​,σa​=n−m∑Pi​−∑Zj​​

5) 会合点与分离点：根轨迹于此会合、分离，对应重根，其坐标 ddd 满足：

∑i=1n1d−Pi=∑j=1m1d−Zj \sum_{i=1}^{n}\frac{1}{d - P_i} = \sum_{j=1}^{m}\frac{1}{d - Z_j} i=1∑n​d−Pi​1​=j=1∑m​d−Zj​1​

或令 dKds∣s=d=0\left.\dfrac{dK}{ds}\right|_{s=d} = 0dsdK​​s=d​=0 求解。

4. 根轨迹性能分析

对主导极点 s1,2=−ζωn±jωn1−ζ2s_{1,2} = -\zeta\omega_n \pm j\omega_n\sqrt{1 - \zeta^2}s1,2​=−ζωn​±jωn​1−ζ2​：

  • 超调量：Mp=e−πζ/1−ζ2M_p = e^{-\pi\zeta/\sqrt{1-\zeta^2}}Mp​=e−πζ/1−ζ2​
  • 调节时间（2%）：ts=4ζωnt_s = \dfrac{4}{\zeta\omega_n}ts​=ζωn​4​

三、从根轨迹到 PID 控制

对一个系统，如果我们对其各项指标有要求，便可通过要求反解出目标极点，再通过设计增益调控根轨迹经过目标极点。

1. P 控制（比例）

K(s)=Kp K(s) = K_p K(s)=Kp​

开环传递函数 L(s)=KpG(s)H(s)L(s) = K_p G(s)H(s)L(s)=Kp​G(s)H(s)。此时根轨迹的形状不变（由被控对象决定），调整 KpK_pKp​ 只改变闭环传递函数的极点在轨迹上的位置。

缺点：

  1. 若目标极点不在根轨迹上，则无法达到目标；
  2. 稳态误差无法消除。

稳态误差分析：

E(s)=R(s)1+KpG(s)H(s) E(s) = \frac{R(s)}{1 + K_p G(s)H(s)} E(s)=1+Kp​G(s)H(s)R(s)​

由终值定理（前提是极限存在）：

lim⁡t→∞f(t)=lim⁡s→0sF(s) \lim_{t\to\infty} f(t) = \lim_{s\to 0} sF(s) t→∞lim​f(t)=s→0lim​sF(s) ess=lim⁡s→0sE(s)=lim⁡s→0sR(s)1+KpG(s)H(s) e_{ss} = \lim_{s\to 0} sE(s) = \lim_{s\to 0} \frac{sR(s)}{1 + K_p G(s)H(s)} ess​=s→0lim​sE(s)=s→0lim​1+Kp​G(s)H(s)sR(s)​

阶跃输入 R(s)=1sR(s) = \frac{1}{s}R(s)=s1​ 时：

ess=11+KpG(0)H(0) e_{ss} = \frac{1}{1 + K_p G(0)H(0)} ess​=1+Kp​G(0)H(0)1​

对于实际系统 G(0)H(0)≠∞G(0)H(0) \ne \inftyG(0)H(0)=∞，仅当 Kp→∞K_p \to \inftyKp​→∞ 时 ess→0e_{ss} \to 0ess​→0；而实际调控中 KpK_pKp​ 过大导致输入过大，故无法消除稳态误差。

2. 超前补偿器（Lead）

要改变轨迹，则需改变极、零点。

K(s)=Kp s+zs+p,z,p∈R,0<z<p K(s) = K_p\,\frac{s + z}{s + p}, \qquad z, p \in \mathbb{R}, \quad 0 < z < p K(s)=Kp​s+ps+z​,z,p∈R,0<z<p

设计目标：让期望的闭环主导极点落在加了补偿器后的根轨迹上。

设计步骤：

  1. 计算相角亏空：ϕ=180°−∠G(s1)H(s1)\phi = 180° - \angle G(s_1)H(s_1)ϕ=180°−∠G(s1​)H(s1​)
  2. 令 ϕ=∠(s1−z)−∠(s1−p)\phi = \angle(s_1 - z) - \angle(s_1 - p)ϕ=∠(s1​−z)−∠(s1​−p)
  3. 选取合适的 zzz 与 ppp
  4. 利用幅值条件求解 KpK_pKp​：
∣Kp s1−zs1−p G(s1)H(s1)∣=1⇒Kp=1∣G(s1)H(s1)⋅s1−ps1−z∣ \left|K_p\,\frac{s_1 - z}{s_1 - p}\,G(s_1)H(s_1)\right| = 1 \Rightarrow K_p = \frac{1}{\left|G(s_1)H(s_1)\cdot\frac{s_1 - p}{s_1 - z}\right|} ​Kp​s1​−ps1​−z​G(s1​)H(s1​)​=1⇒Kp​=​G(s1​)H(s1​)⋅s1​−zs1​−p​​1​

为了达到同样的目标，还可以令 K(s)=K1s+KpK(s) = K_1 s + K_pK(s)=K1​s+Kp​，即典型的 PD 控制，但其缺点是对高频信号放大明显，会使系统对高频噪声敏感。

3. 消除稳态误差

滞后补偿器：K(s)=Kp s+zs+pK(s) = K_p\,\dfrac{s + z}{s + p}K(s)=Kp​s+ps+z​，其中 0<p<z0 < p < z0<p<z 且 ∣p∣,∣z∣|p|, |z|∣p∣,∣z∣ 较小。

闭环误差：

E(s)=R(s)1+K(s)G(s)H(s)=R(s)1+KpG(s)H(s)⋅s+zs+p E(s) = \frac{R(s)}{1 + K(s)G(s)H(s)} = \frac{R(s)}{1 + K_p G(s)H(s)\cdot\frac{s + z}{s + p}} E(s)=1+K(s)G(s)H(s)R(s)​=1+Kp​G(s)H(s)⋅s+ps+z​R(s)​

阶跃输入下的稳态误差：

ess=lim⁡s→0sE(s)=11+KpG(0)H(0)⋅zp e_{ss} = \lim_{s\to 0} sE(s) = \frac{1}{1 + K_p G(0)H(0)\cdot\frac{z}{p}} ess​=s→0lim​sE(s)=1+Kp​G(0)H(0)⋅pz​1​

因为 p<zp < zp<z，所以 KpG(0)H(0)⋅zp>KpG(0)H(0)K_p G(0)H(0)\cdot\frac{z}{p} > K_p G(0)H(0)Kp​G(0)H(0)⋅pz​>Kp​G(0)H(0)，达到了减小 esse_{ss}ess​ 的目的。

极限 p→0p \to 0p→0 时，ess→0e_{ss} \to 0ess​→0，此时：

K(s)=Kp s+zs=Kp+Kpzs=Kp+Kis K(s) = K_p\,\frac{s + z}{s} = K_p + K_p\frac{z}{s} = K_p + \frac{K_i}{s} K(s)=Kp​ss+z​=Kp​+Kp​sz​=Kp​+sKi​​

为典型的 PI 控制。

4. P、超前、滞后分析

对于恒定增益 KpK_pKp​，其在高低频处的增益一致，无法改变根轨迹形态，也无法消除稳态误差。

对于超前/滞后补偿器 K(s)=Kps+zs+pK(s) = K_p\dfrac{s + z}{s + p}K(s)=Kp​s+ps+z​：

  • 原点处增益：K(0)=KpzpK(0) = K_p\dfrac{z}{p}K(0)=Kp​pz​
  • 高频处增益：K(s)≈Kp1+z/s1+p/sK(s) \approx K_p\dfrac{1 + z/s}{1 + p/s}K(s)≈Kp​1+p/s1+z/s​
K(s)K(s)K(s) 的取值会影响极、零点位置，从而影响系统闭环瞬态（影响幅值条件与相位条件，决定闭环极点移动）；而当 ∣K(s)∣≈1|K(s)| \approx 1∣K(s)∣≈1 且 ∠K(s)≈0°\angle K(s) \approx 0°∠K(s)≈0° 时影响很小。

阶跃输入下：ess=11+K(0)G(0)H(0)e_{ss} = \dfrac{1}{1 + K(0)G(0)H(0)}ess​=1+K(0)G(0)H(0)1​，K(0)↑⇒ess↓K(0) \uparrow \Rightarrow e_{ss} \downarrowK(0)↑⇒ess​↓，而 K(0)=KpzpK(0) = K_p\frac{z}{p}K(0)=Kp​pz​，故需要增大 zp\frac{z}{p}pz​。

如何做到既调控闭环极点（瞬态）又减小稳态误差（稳态）？—— 同时采用多个控制器：

  • K(s)=KpK(s) = K_pK(s)=Kp​（z=p=0z = p = 0z=p=0）
  • K(s)=Kps+zs+pK(s) = K_p\frac{s + z}{s + p}K(s)=Kp​s+ps+z​，0<z<p0 < z < p0<z<p（**超前**，调瞬态）
  • K(s)=Kps+zs+pK(s) = K_p\frac{s + z}{s + p}K(s)=Kp​s+ps+z​，0<p<z0 < p < z0<p<z（**滞后**，调稳态）

为了使滞后不影响已调好的闭环极点，其 ppp 应足够小；当 p→0p \to 0p→0 变为 PI 控制。

5. PID 控制

将超前、滞后复合，便得到 PID 控制：

K(s)=Kp+Kis+Kds K(s) = K_p + \frac{K_i}{s} + K_d s K(s)=Kp​+sKi​​+Kd​s ⇒K(s)=Kds2+Kps+Kis=Kd(s−z1)(s−z2)s \Rightarrow K(s) = \frac{K_d s^2 + K_p s + K_i}{s} = \frac{K_d(s - z_1)(s - z_2)}{s} ⇒K(s)=sKd​s2+Kp​s+Ki​​=sKd​(s−z1​)(s−z2​)​

即 两个零点 + 一个在原点的极点：利用 z1,z2z_1, z_2z1​,z2​ 调极点（瞬态），原点的极点消除稳态误差（p→0p \to 0p→0 的稳态）。

6. PID 设计流程

设计流程：先 PD 定瞬态，再 PI 调稳态

① 设定目标极点：s=−ζωn±jωn1−ζ2s = -\zeta\omega_n \pm j\omega_n\sqrt{1 - \zeta^2}s=−ζωn​±jωn​1−ζ2​

② PD：KPD(s)=kp+kds=kd(s+z)K_{PD}(s) = k_p + k_d s = k_d(s + z)KPD​(s)=kp​+kd​s=kd​(s+z)——反解零点，使目标极点落在根轨迹上

③ PI：KPI(s)=1+kis=s+kisK_{PI}(s) = 1 + \frac{k_i}{s} = \frac{s + k_i}{s}KPI​(s)=1+ski​​=ss+ki​​——对应原点处的极零点

④ PID：

KPID(s)=KPD×KPI=kd(s+z)(s+ki)s K_{PID}(s) = K_{PD} \times K_{PI} = \frac{k_d(s + z)(s + k_i)}{s} KPID​(s)=KPD​×KPI​=skd​(s+z)(s+ki​)​
